# Hospital Management System

A complete Hospital Management System developed using PHP, MySQL, Bootstrap, and XAMPP.  
This project helps manage patients, doctors, appointments, and billing through a modern and user-friendly interface.

---

## Features
- Admin Login System
- Patient Management (CRUD)
- Doctor Management (CRUD)
- Appointment Booking System (CRUD)
- Billing Management (CRUD)
- Responsive Dashboard
- Mobile-Friendly Responsive UI (Optional)
- Online Deployment Support (Optional)

---

## Technologies Used
- PHP
- MySQL
- Bootstrap 5
- XAMPP
- phpMyAdmin
